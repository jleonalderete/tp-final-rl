# Merton, Kelly, and the no-trade band with RL

[![CI](https://github.com/jleonalderete/tp-final-rl/actions/workflows/ci.yml/badge.svg)](https://github.com/jleonalderete/tp-final-rl/actions/workflows/ci.yml)

Final project for the Reinforcement Learning course at Universidad de San Andrés (2026), by
Joaquín León Alderete and Santino Domato.

## Goal

An agent splits its wealth between a simulated risky asset and a risk-free one, and maximizes
the logarithmic utility of terminal wealth. Each step's reward is the log-return of wealth, so
the rewards add up to the log of terminal wealth.

1. **Validation without costs.** The optimal policy holds the Merton fraction
   $\pi^* = (\mu - r)/\sigma^2$ constant, the same idea as the Kelly criterion. Check that the
   agent recovers it.
2. **Proportional transaction costs.** The optimum becomes a no-trade band around $\pi^*$:
   don't trade while the current fraction stays inside it. Analyze whether the agent learns it.
3. **Band width as a function of cost.** Check whether the band widens as costs rise, as theory
   predicts.

Assignment: [`docs/assignment.md`](docs/assignment.md).

## Setup

Requires [uv](https://docs.astral.sh/uv/) and, for the report,
[Tectonic](https://tectonic-typesetting.github.io/). Any LaTeX distribution with `latexmk` also
works.

```bash
uv sync                      # .venv with Python 3.14 and all dependencies, dev tools included
uv run pre-commit install    # pre-commit and commit-msg hooks, once per clone
```

## Commands

```bash
uv run pre-commit run --all-files    # formatting, linting, type checking, and the other hooks
uv run pytest                        # tests
uv run tensorboard --logdir runs     # training curves
tectonic report/main.tex             # builds report/main.pdf
```
